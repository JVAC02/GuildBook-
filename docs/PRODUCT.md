# GuildBook — Produto

## Objetivo

Criar uma ferramenta médica rápida para consulta e prescrição.

## Princípio principal

O médico deve chegar à informação com o menor número possível de ações.

Não solicitar dados que não alteram a conduta.

## Fluxo principal

Medicamento
→ apresentação
→ população, quando necessária
→ esquema
→ duração
→ quantidade automática
→ receituário

## Fase 1

Medicamentos modelo:

1. Dipirona
2. Cetoprofeno

Eles definirão:
- schema;
- componente visual;
- cálculo;
- receituário;
- adulto/pediatria;
- apresentações;
- contexto ambulatorial/assistencial.

Nenhum terceiro medicamento será adicionado antes da aprovação desses dois.
